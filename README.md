#  Global Superstore Sales Analysis Dashboard

##  Overview
The **Global Superstore Dataset** is a widely used business dataset containing information about sales, profit, customers, products, and shipping across different regions.

This project focuses on building an **interactive Business Intelligence (BI) dashboard** using Python and Streamlit.

##  Objectives
- Clean and preprocess raw sales data
- Perform exploratory data analysis
- Build an interactive dashboard using Streamlit
- Analyze business performance using KPIs

##  Dashboard Features
- Region-wise filtering
- Category and Sub-category analysis
- KPI tracking:
  - Total Sales
  - Total Profit
- Top 5 Customers by Sales
- Interactive visualizations

##  Skills Gained
- Business Intelligence (BI) Dashboarding
- Data Storytelling
- Streamlit Dashboard Development
- KPI Analysis
- Data Cleaning & Visualization

# Term Deposit Subscription Prediction (Bank Marketing)

##  Introduction
Banks use direct marketing campaigns to promote term deposits. This project aims to predict whether a customer will subscribe to a term deposit using machine learning techniques.

##  Objectives
- Explore and understand customer marketing data
- Preprocess and encode categorical variables
- Build classification models:
  - Logistic Regression
  - Random Forest Classifier
- Evaluate models using:
  - Confusion Matrix
  - F1-Score
  - ROC Curve & AUC Score
- Apply Explainable AI (SHAP) for model interpretability
- Explain at least 5 individual predictions

##  Techniques Used
- Data Preprocessing & Feature Encoding
- Supervised Machine Learning
- Model Evaluation Metrics
- Explainable AI (XAI - SHAP)

##  Skills Gained
- Classification Modeling
- Feature Engineering
- Model Evaluation
- Explainable AI (SHAP)
- Customer Behavior Analysis
